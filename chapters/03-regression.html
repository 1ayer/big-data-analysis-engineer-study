목표변수·식·손실함수·계수 해석

회귀분석과 로지스틱 회귀분석을 목표변수, 식, 손실함수와 계수 해석을 기준으로 비교한다.

3분 · 사전 점검

목표변수부터 구분하기

  1. 아파트 가격을 예측할 때와 대출 연체 여부를 예측할 때 각각 어떤 모형을 고를까?
  2. 로지스틱 회귀는 이름에 ‘회귀’가 있는데 왜 분류 모형일까?
  3. 로그 오즈가 0이면 사건이 일어날 확률은 얼마인가?

지금 답을 확인하지 말고, 단원 끝에서 같은 질문에 다시 답한다.

핵심 관계

첫 질문은 “무엇을 예측하는가?”

구분 선형회귀 로지스틱 회귀
목표변수 연속형 수치 범주형 레이블
대표 질문 매출이 얼마인가? 이탈할 것인가?
기본 출력 제한 없는 수치 예측값 ŷ 0과 1 사이의 사건 확률 p
핵심 변환 선형식 그대로 사용 선형식 z를 시그모이드에 통과
scikit-learn LinearRegression LogisticRegression

1. 선형회귀: 수치를 직접 예측한다

ŷ = β0 + β1x1 + … + βpxp

관측값 y와 예측값 ŷ의 차이가 잔차다. 보통의 최소제곱 선형회귀는 잔차 제곱합 Σ(y − ŷ)2이 가장 작아지는 계수를 찾는다.

다른 변수가 같을 때 xj가 1 증가하면 예측값은 βj만큼 변한다. 이 직접적인 단위 해석이 선형회귀의 장점이다.

시험에서 묻는 경계: ‘선형’은 설명변수의 모양이 반드시 직선이라는 뜻이 아니라 미지의 계수에 대해 선형이라는 뜻이다. x2을 변수로 넣어도 계수가 선형으로 결합되면 선형모형이다.

2. 로지스틱 회귀: 선형식을 확률로 바꾼다

z = β0 + Σβjxj → p = 1 / (1 + e−z)

선형식 z는 음의 무한대부터 양의 무한대까지 갈 수 있다. 시그모이드 함수는 이를 0과 1 사이의 확률로 눌러 넣는다. 확률에 기준값을 적용하면 최종 범주를 정할 수 있다.

z = 0p = 0.5
z > 0p > 0.5
z < 0p < 0.5

따라서 로지스틱 회귀는 이름과 달리 머신러닝에서는 분류 모형이다. predict_proba()는 클래스별 확률을, predict()는 최종 레이블을 돌려준다.

3. 확률 → 오즈 → 로그 오즈

확률p
오즈p / (1 − p)
로그 오즈ln[p / (1 − p)] = z

사건 확률이 0.8이면 오즈는 0.8 / 0.2 = 4, 즉 사건이 일어날 쪽이 일어나지 않을 쪽보다 4배 유리하다는 뜻이다.

다른 변수가 같을 때 xj가 1 증가하면 로그 오즈는 βj만큼 변하고, 오즈는 eβj배가 된다.

4. 적합·가정·규제를 한 흐름으로 본다

선형회귀의 잔차는 관측값에서 예측값을 뺀 값이다. 잔차 그림은 선형 관계, 등분산성, 독립성, 이상점 같은 문제를 탐색하는 출발점이다. 잔차의 정규성은 특히 작은 표본에서 계수에 대한 추론과 연결되며, 예측값 자체가 정규분포여야 한다는 뜻은 아니다.

설명변수들이 매우 강하게 선형 결합되면 다중공선성 때문에 개별 계수 추정이 불안정해질 수 있다. Ridge의 L2 벌점은 계수를 함께 줄이고, Lasso의 L1 벌점은 일부 계수를 정확히 0으로 만들 수 있다. 규제는 학습오차만 최소화하는 대신 계수 크기에 비용을 더해 복잡성과 분산을 줄이려는 절충이다.

로지스틱 회귀는 선형회귀처럼 확률과 관측값의 제곱오차를 맞추는 것이 아니라, 관측 클래스의 가능도를 높이도록 로그손실을 최소화한다. 시그모이드 출력이 0 또는 1에 매우 확신했는데 틀리면 로그손실이 크게 증가한다.

구분 기준 · 두 회귀모형: 두 모형은 모두 입력의 선형결합에서 출발하지만 ‘무엇과 비교해 오차를 줄이는가’가 다르다. 선형회귀는 수치 잔차를, 로지스틱 회귀는 클래스 확률의 로그손실을 본다.

시험과 실기의 혼동 지점

  • 로지스틱 회귀 = 분류: 연속 확률을 만들지만 목표변수는 범주형이다.
  • 확률과 오즈는 다르다: 확률 0.8의 오즈는 0.8이 아니라 4다.
  • 작은 C = 강한 규제: scikit-learn의 C는 규제 강도의 역수다.
  • 최소제곱은 이상값에 민감: 큰 잔차를 제곱하므로 영향이 커진다.
  • R²가 높아도 인과는 아님: 설명·예측 관계만으로 원인효과를 확정할 수 없다.
  • 다중공선성은 계수 해석 문제: 예측이 가능해도 개별 계수의 부호·크기가 불안정할 수 있다.

5분 · 답을 보지 않고 떠올리기

먼저 답해 보고 펼쳐 보세요

1. 두 모형을 고르는 첫 기준은?

목표변수의 형태다. 연속형 수치면 선형회귀, 범주형 레이블이면 로지스틱 회귀를 먼저 고려한다.

2. 최소제곱 선형회귀가 최소화하는 것은?

관측값과 예측값 차이인 잔차의 제곱합이다.

3. 로지스틱 회귀가 확률을 만드는 두 단계는?

먼저 설명변수의 선형결합 z를 만들고, z를 시그모이드 함수에 넣어 0과 1 사이의 확률을 얻는다.

4. 확률 0.75의 오즈는?

0.75 / 0.25 = 3이다.

5. 로지스틱 계수 β를 지수화한 eβ의 의미는?

다른 변수가 같을 때 해당 변수가 1 증가함에 따라 오즈가 몇 배가 되는지를 뜻한다.

6. predict()와 predict_proba()의 차이는?

전자는 최종 클래스 레이블, 후자는 각 클래스의 예측 확률을 반환한다.

7. 잔차는 어떻게 계산하는가?

관측값 y에서 예측값 ŷ를 뺀 y−ŷ다.

8. 다중공선성이 강하면 어떤 해석 문제가 생기는가?

다른 변수를 통제한 개별 계수의 크기와 부호가 표본 변화에 민감해져 불안정할 수 있다.

9. Ridge와 Lasso의 대표 벌점 차이는?

Ridge는 계수 제곱합인 L2, Lasso는 계수 절댓값 합인 L1 벌점을 쓰며 Lasso는 일부 계수를 0으로 만들 수 있다.

10. 로지스틱 회귀의 대표 손실은?

관측 클래스의 확률에 기반한 로그손실, 즉 이진 교차엔트로피다.

5분 · 선택지 변별

10문제로 두 회귀모형 구분하기

  1. 고객의 다음 달 구매금액을 예측하는 데 가장 직접적으로 맞는 모형은?

    1. 선형회귀
    2. 로지스틱 회귀
    3. 연관성분석
    4. 군집분석
    정답과 선택지 해설

    A. 구매금액은 연속형 목표변수다. B는 범주 분류, C는 동시 발생 규칙, D는 레이블 없는 집단 탐색에 맞는다.

  2. 로지스틱 회귀의 선형결합 z가 0일 때 사건 확률은?

    1. 0
    2. 0.25
    3. 0.5
    4. 1
    정답과 선택지 해설

    C. 1/(1+e0)=1/2이다. A·B·D는 z=0의 시그모이드 출력이 아니다.

  3. 사건 확률이 0.8일 때 오즈는?

    1. 0.2
    2. 0.8
    3. 1.25
    4. 4
    정답과 선택지 해설

    D. p/(1−p)=0.8/0.2=4다. B는 확률 자체, A는 비사건 확률, C는 계산식의 역방향에 가깝다.

  4. 다음 중 옳은 설명은?

    1. 로지스틱 회귀의 목표변수는 반드시 연속형이다.
    2. 선형모형은 설명변수에 제곱항을 포함할 수 없다.
    3. 로지스틱 회귀의 계수는 로그 오즈의 변화량으로 해석할 수 있다.
    4. 최소제곱법은 큰 잔차의 영향을 줄인다.
    정답과 선택지 해설

    C. 계수는 로그 오즈 변화량이다. A는 범주형 목표를, B는 계수에 대한 선형성을, D는 제곱오차의 방향을 잘못 설명한다.

  5. scikit-learn의 LogisticRegression에서 다른 조건이 같을 때 C를 줄이면?

    1. 규제가 강해진다.
    2. 규제가 약해진다.
    3. 목표변수가 연속형으로 바뀐다.
    4. 항상 정확도가 높아진다.
    정답과 선택지 해설

    A. C는 규제 강도의 역수이므로 작을수록 규제가 강하다. B는 반대이고 C·D는 C가 보장하지 않는다.

  6. 선형회귀의 잔차 정의로 옳은 것은?

    1. 예측값 − 관측값
    2. 관측값 − 예측값
    3. 관측값 × 예측값
    4. 예측값의 제곱
    정답과 선택지 해설

    B. 잔차는 y−ŷ다. A는 부호가 반대이며 C·D는 오차의 정의가 아니다.

  7. 다중공선성이 강할 때 가장 직접적인 문제는?

    1. 목표변수가 자동 범주형이 된다.
    2. 개별 회귀계수 추정이 불안정해질 수 있다.
    3. 잔차가 항상 0이 된다.
    4. 관측 수가 자동 증가한다.
    정답과 선택지 해설

    B. 설명변수들이 서로 강하게 겹치는 정보를 가지면 개별 효과 분리가 어렵다. A·C·D는 따라오지 않는다.

  8. 일부 회귀계수를 정확히 0으로 만들 수 있는 대표 규제는?

    1. L1
    2. L2만
    3. 잔차 제곱
    4. 오즈 변환
    정답과 선택지 해설

    A. Lasso의 L1 벌점은 희소한 해를 만들 수 있다. L2는 보통 0에 가깝게 줄이고 C·D는 해당 규제가 아니다.

  9. 로지스틱 회귀에서 실제 클래스가 1일 때 어느 예측이 로그손실이 가장 큰가?

    1. p=0.99
    2. p=0.8
    3. p=0.5
    4. p=0.01
    정답과 선택지 해설

    D. 실제 1에 거의 0이라고 자신 있게 틀린 경우 −log(p)가 가장 크다. A는 가장 작은 손실, B·C는 그 중간이다.

  10. 결정계수 R²가 매우 높을 때 반드시 참인 것은?

    1. 설명변수가 목표변수의 원인이다.
    2. 새 데이터 성능도 완벽하다.
    3. 학습 자료에서 분산 설명 비율이 높다.
    4. 다중공선성이 없다.
    정답과 선택지 해설

    C. R²는 해당 자료의 분산 설명과 연결된다. 인과·일반화·공선성 부재는 A·B·D처럼 보장하지 않는다.

2분+ · Python 연결

같은 선형식에서 연속값·확률 출력 비교

아래 예제는 표준 라이브러리만 사용해 선형 예측과 시그모이드 변환을 계산한다. 실행 파일 내려받기 

from math import exp

def linear_prediction(x, coefficients, intercept=0.0):
    return intercept + sum(a * b for a, b in zip(x, coefficients))

def sigmoid(z):
    return 1 / (1 + exp(-z))

z = linear_prediction([2.0], [1.0], intercept=-1.0)
print(z)           # 1.0: 선형회귀라면 수치 예측값
print(sigmoid(z))  # 0.731...: 로지스틱 회귀라면 사건 확률

scikit-learn에서는

from sklearn.linear_model import LinearRegression, LogisticRegression

reg = LinearRegression().fit(X_train, y_amount)
amount = reg.predict(X_test)

clf = LogisticRegression().fit(X_train, y_yes_no)
label = clf.predict(X_test)
probability = clf.predict_proba(X_test)[:, 1]

두 번째 코드는 scikit-learn이 설치된 실기 환경에서 실행한다.
