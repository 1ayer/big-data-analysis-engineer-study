핵심 1 · 정제와 통합

결측·이상·중복의 원인을 먼저 분류한다

1. 품질 문제는 정확성만이 아니다

품질 축질문예시
완전성필수 값이 존재하는가?가입일 누락
유효성형식·범위·도메인 규칙을 지키는가?월이 13, 음수 나이
일관성표·시점·시스템 사이 값이 맞는가?주문합계와 품목합계 불일치
유일성한 실체가 불필요하게 중복되지 않는가?동일 거래 이중 적재
적시성목적에 필요한 시점까지 갱신되는가?한 달 늦은 재고

타입 변환에 성공했다는 사실은 값이 업무적으로 타당하다는 뜻이 아니다. 날짜 파싱 뒤 미래 날짜인지, 범주 코드가 허용 목록에 있는지, 금액과 수량의 부호가 거래 유형과 맞는지를 함께 검사한다.

2. 결측은 표시법과 발생 이유를 분리해서 본다

NaN, 빈 문자열, -999, “미상”은 모두 결측을 나타낼 수 있지만 자료형과 도구가 다르게 처리한다. 먼저 명시적 결측 표현으로 통일하고 isna 같은 전용 판별을 쓴다. 특히 NaN은 자기 자신과의 동등 비교도 일반 숫자와 다르므로 x == NaN에 기대지 않는다.

구분뜻해석 예
MCAR결측 여부가 관측·미관측 값과 무관임의의 전송 장애
MAR관측된 다른 변수로 결측을 설명 가능연령대별 응답률 차이
MNAR결측 여부가 결측된 값 자체와 관련고소득자가 소득 응답을 더 회피

메커니즘은 데이터만 보고 언제나 확정할 수 있는 라벨이 아니다. 수집 과정과 업무 지식을 함께 살피며, 가정이 결과에 주는 영향을 민감도 분석으로 확인할 수 있다.

전략적합할 수 있는 상황주요 위험
행·열 삭제결측이 적고 삭제 편향이 작음표본 감소, 선택 편향
상수·최빈값범주형 “미상” 자체에 의미가짜 빈도 집중
평균·중앙값빠른 단변량 대체, 중앙값은 극단값에 강함분산과 변수 관계 축소
모형 기반다른 변수 관계를 활용모형 가정·복잡성, 불확실성 과소평가
결측 표시 변수빠진 사실 자체가 신호대체값과 함께 신중히 해석
이해 포인트: 평균 대체는 빈칸을 평균에 쌓으므로 중심은 안정돼 보여도 값들이 평균 주위로 인위적으로 모인다. 그래서 변동성과 변수 사이 관계가 약해질 수 있다.

3. 이상값은 통계적 희귀성과 데이터 오류를 구분한다

z 점수z = (x − x̄) / s
사분위 범위IQR = Q3 − Q1
상자그림 경계Q1 − 1.5IQR, Q3 + 1.5IQR

z 점수는 평균과 표준편차에 기대므로 비대칭 분포나 극단값에 민감하다. IQR 경계는 순위 기반이라 더 강건하지만, 경계 밖이라는 사실만으로 오류를 증명하지 않는다. 희귀한 대형 거래는 분석 대상일 수 있고, 키 입력 실수로 생긴 300세는 수정 또는 결측 전환 대상이다.

  1. 탐지상자그림·산점도·규칙·z 점수 등으로 후보를 찾는다.
  2. 확인원천 기록, 단위, 입력 과정, 업무 맥락을 대조한다.
  3. 처리수정·제거·변환·절단·강건한 방법·별도 집단 중 선택한다.
  4. 비교처리 전후 표본 수, 분포, 결론과 성능 변화를 기록한다.

시험 함정: 경계는 판결문이 아니다

  • 상자그림 경계 밖 값은 이상값 후보이지 자동 삭제 대상이 아니다.
  • 극단값을 평균으로 대체하면 중요한 꼬리 정보를 없앨 수 있다.
  • 로그 변환은 오른쪽 꼬리를 줄일 수 있지만 0·음수와 해석 변화를 점검한다.

4. 통합은 조인 성공보다 행의 의미 보존이 중요하다

자료형과 단위, 시간대, 코드 체계, 키의 유일성을 맞춘 뒤 결합한다. 일대일로 예상한 키가 실제로 일대다이면 행 수와 합계가 부풀 수 있다. pandas의 merge(validate=...)처럼 예상 관계를 검증하는 장치를 쓰면 조용한 중복 증식을 막을 수 있다.

점검결합 전결합 후
키NULL·중복·형식 확인미매칭·다중매칭 확인
행기대 관계 1:1, 1:N 정의행 수 증감과 원인 확인
측정원화/달러, kg/g, 시간대 통일합계·범위·대표 표본 재검산
중복자연키·업무 정의 결정완전 중복과 정상 반복거래 구분

핵심 2 · 변환과 축소

모형이 읽을 표현으로 바꾸되 정보를 잃는 이유를 안다

1. 표준화와 최소-최대 정규화

방법공식·결과특징
표준화z = (x − x̄) / s평균 0, 표준편차 1을 목표; 범위 제한 없음
최소-최대(x − min) / (max − min)보통 [0,1]; 극단값에 민감
강건 스케일(x − median) / IQR중앙값·IQR 사용; 극단값 영향 감소
로그log(x) 또는 log(1+x)곱셈 관계·오른쪽 꼬리 완화; 정의역 확인

거리·내적·경사 기반 모형은 큰 단위의 변수가 계산을 지배할 수 있어 스케일 조정의 영향을 크게 받는다. 의사결정나무처럼 한 변수의 임계값으로 분할하는 방법은 단조 스케일 변환에 상대적으로 덜 민감하다.

2. 범주형 값은 순서의 존재 여부가 핵심이다

  • 명목형: 혈액형·지역처럼 순서가 없으므로 원-핫 인코딩이 대표적이다.
  • 순서형: 낮음·보통·높음처럼 순서는 있지만 간격이 같다고 단정할 수 없다.
  • 레이블 정수화 함정: 서울=1, 부산=2, 제주=3은 제주가 서울보다 “세 배”라는 거리를 만든다.
  • 고카디널리티: 범주가 너무 많으면 원-핫 차원이 커진다. 희귀 범주 묶기나 문제에 맞는 인코딩을 검토한다.

구간화는 연속값을 범주로 줄여 해석과 비선형 패턴 표현을 도울 수 있지만, 구간 안 차이를 버리고 경계 근처의 작은 차이를 크게 만들 수 있다. 동일 간격과 동일 빈도 구간화는 목적이 다르다.

3. 축소는 표본·변수·표현의 세 경로가 있다

경로방법 예보존하려는 것
표본 축소단순·층화·군집 표본추출모집단 대표성과 희귀 집단
변수 선택필터·래퍼·임베디드원래 변수의 해석 가능성
차원 추출PCA 등정보를 새 축에 압축
집계·압축시간·공간 집계, 비닝분석에 필요한 해상도

필터 방식은 상관·검정·정보량 등 모형 밖 기준으로 빠르게 고르고, 래퍼는 변수 조합별 모형 성능을 반복 평가하며, 임베디드는 L1 규제나 나무처럼 학습 과정 안에서 선택한다. 선택 기준도 학습 데이터에서만 추정한다.

4. 클래스 불균형은 정확도보다 평가 설계부터 바꾼다

양성 1% 자료에서 모두 음성이라 답하면 정확도는 99%지만 양성을 하나도 찾지 못한다. 층화 분할로 평가 집합의 비율을 관리하고 혼동행렬·정밀도·재현율 같은 지표를 본 뒤, 필요하면 클래스 가중치나 학습 집합의 과소·과대표집을 검토한다.

시험과 실기의 혼동 지점

  • 표준화 ≠ 정규분포화: 평균과 스케일을 바꿀 뿐 분포 모양을 자동으로 정규분포로 만들지 않는다.
  • 정규화: 문맥에 따라 [0,1] 스케일 또는 벡터 노름 변환을 가리킬 수 있어 공식을 확인한다.
  • 재표집은 학습 집합에서: 시험 분포를 인위적으로 바꾸면 운영 성능 해석이 흐려진다.
  • fit은 학습만: 대체값·스케일·범주 목록·선택 기준은 학습 데이터로 정하고 나머지에 적용한다.

7분 · 폐쇄형 회상

답을 말한 뒤 펼치기

1. 데이터 품질의 다섯 점검 축은?

완전성, 유효성, 일관성, 유일성, 적시성이다.

2. NaN을 동등 비교 대신 전용 함수로 확인하는 이유는?

NaN은 일반 숫자와 달리 자기 자신과도 같지 않은 비교 의미를 가지므로 isna·isnan 등을 써야 한다.

3. MCAR·MAR·MNAR의 차이는?

결측이 모든 값과 무관, 관측값으로 설명 가능, 미관측된 값 자체와 관련인 경우다.

4. 평균 대체의 대표적인 부작용은?

값을 평균에 집중시켜 분산과 다른 변수와의 관계를 약화할 수 있다.

5. 결측 표시 변수를 추가할 이유는?

값이 빠졌다는 사실 자체가 목표와 관련된 신호일 수 있기 때문이다.

6. IQR과 대표 이상값 경계식은?

IQR=Q3−Q1이며, 대표 경계는 Q1−1.5IQR과 Q3+1.5IQR이다.

7. 통계적 이상값을 자동 삭제하면 안 되는 이유는?

오류가 아니라 희귀하지만 유효하고 중요한 관측일 수 있기 때문이다.

8. 조인 전후에 키와 행 수를 확인하는 이유는?

예상하지 않은 다중 매칭과 중복 증식으로 합계와 관측 단위가 바뀌는 일을 막기 위해서다.

9. 표준화와 최소-최대 변환의 결과 차이는?

표준화는 평균 0·표준편차 1을 목표로 범위를 제한하지 않고, 최소-최대는 보통 [0,1] 범위로 옮긴다.

10. 명목형 범주를 단순 정수화할 때의 위험은?

실제로 없는 순서와 거리 관계를 모형에 부여할 수 있다.

11. 필터·래퍼·임베디드 변수 선택의 차이는?

각각 모형 밖 통계 기준, 변수 조합의 반복 성능, 모형 학습 과정 안에서 선택한다.

12. 전처리 누수를 막는 기본 규칙은?

먼저 데이터를 분할하고 학습 데이터로만 변환 기준을 fit한 뒤 검증·시험 데이터에는 transform만 한다.

    1. 완전성
    2. 적시성

중앙값 대체·z 점수·IQR을 계산한다

표준 라이브러리 예제는 학습 자료에서만 중앙값과 경계를 계산하고, 원본 목록을 바꾸지 않았는지까지 확인한다. 실행 파일 내려받기

from statistics import mean, median, stdev

fill_value = median(x for x in train if x is not None)
filled = [fill_value if x is None else x for x in train]
z_scores = [(x - mean(filled)) / stdev(filled) for x in filled]

실무의 pandas·scikit-learn에서는 대체기와 변환기를 파이프라인 안에 두어 학습과 적용 경계를 일관되게 관리한다.
