실행 파일 내려받기

실제 시험 환경의 패키지와 버전은 해당 회차의 공식 안내를 따르세요. 이 예제는 학습용 흐름이며 의료 판단에 쓰는 모형이 아닙니다.

전체 흐름

각 단계가 다음 단계의 경계를 만든다

1. 읽기와 품질 점검

pd.read_csv 뒤에 목표값이 0·1인지 확인하고, 연습을 위해 일부 mean area 값에 만든 결측은 파이프라인 안에서 처리합니다. 자료형·행 수·결측·중복·목표 분포는 모형보다 먼저 확인할 항목입니다.

2. 분할과 파생변수

반지름/둘레 비율과 고정 경계의 질감 구간을 만듭니다. 두 변수 모두 한 행의 현재 입력만 사용해 미래 정보나 전체 자료의 통계량을 보지 않습니다. 그 뒤 목표 비율을 보존한 학습·시험 분할로 최종 평가 자료를 봉인합니다.

3. 전처리 파이프라인

수치형은 중앙값 대체와 표준화, 범주형은 최빈값 대체와 원-핫 인코딩을 적용합니다. ColumnTransformer와 Pipeline으로 묶었기 때문에 교차검증의 각 학습 폴드에서만 대체값·평균·범주 목록을 학습합니다.

4. 기준모형과 후보 비교

해석 가능한 로지스틱 회귀를 기준선으로 두고 랜덤 포레스트와 비교합니다. 학습 자료 안의 5-fold 층화 교차검증 ROC-AUC로 후보를 고르며, 최종 시험 자료는 이 선택에 쓰지 않습니다.

5. 독립 평가와 저장

선택이 끝난 모형을 전체 학습 자료에 적합하고 시험 ROC-AUC·F1을 한 번 계산합니다. 행 ID, 실제값, 예측값, 악성 확률을 CSV로 저장해 후속 검토가 가능하게 합니다.

핵심 코드

누수 방지는 파이프라인의 위치로 드러나요

numeric = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("scale", StandardScaler()),
])
categorical = Pipeline([
    ("impute", SimpleImputer(strategy="most_frequent")),
    ("one_hot", OneHotEncoder(handle_unknown="ignore")),
])
preprocess = ColumnTransformer([
    ("numeric", numeric, numeric_columns),
    ("categorical", categorical, categorical_columns),
])
pipeline = Pipeline([("preprocess", preprocess), ("model", model)])

cv_auc = cross_val_score(
    pipeline, train_x, train_y,
    cv=StratifiedKFold(5, shuffle=True, random_state=42),
    scoring="roc_auc",
).mean()

전체 자료를 먼저 fit_transform한 뒤 교차검증하는 코드보다 길지만, 평가 폴드가 중앙값과 스케일에 들어가지 않는다는 계약이 코드 구조에 남습니다.

점수보다 먼저 네 가지를 설명해 보세요

  1. 악성을 양성 1로 바꾼 이유와 F1의 양성 방향은 무엇인가?

  3. 로지스틱 회귀와 랜덤 포레스트의 교차검증 점수 차이가 작다면 무엇을 더 비교할 것인가?
  4. 0.5 임계값을 바꾸려면 어떤 오류비용과 처리 용량이 필요한가?
