    학습 완료는 페이지 열람이 아니라 회상과 문제 풀이 뒤에 판단한다. 각 페이지 아래에서 실제 학습일과 현재 상태를 기록한다. 회상과 간격 복습의 근거는 Roediger & Karpicke(2006), Cepeda 등(2008)을 참고했다. 1·3·7·14일 간격은 이 사이트의 단순 시작 규칙이며 공식 권고가 아니다.

    카드와 학습 데이터

    필요한 것만 저장하고 전체 기록을 백업한다

    개념·회상·문제의 ☆ 카드 후보를 누르면 현재 브라우저에 모인다. 화면 아래 저장한 카드에서 Anki용 TSV를 만들거나 카드·오개념·학습 기록을 하나의 JSON 파일로 백업할 수 있다.

    계정 동기화 기능은 없다. 브라우저 데이터를 지우거나 기기를 바꾸기 전에 JSON 백업을 내려받는다. 복원은 파일 전체로 교체하며, 형식이 잘못된 파일은 적용하지 않는다.
