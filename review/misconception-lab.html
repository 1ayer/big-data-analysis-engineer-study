오답 규칙 복원과 적용 경계 교정

오개념 교정 순서

정답보다 내가 적용한 규칙을 먼저 복원하세요

  1. 조건 복원정답을 가른 목표변수·자료 구조·비교 기준을 적으세요.
  2. 내 규칙 복원답을 고를 때 사용한 정의·공식·가정을 한 문장으로 적으세요.
  3. 경계 대조그 규칙이 성립하는 조건과 오답이 되는 반례를 나누세요.
  4. 규칙 교정“A이면 B다. 단, C에서는 D와 구분한다” 형태로 다시 쓰세요.

이 페이지는 실제 기출문제를 제공하는 자료가 아니라 사용자가 자신의 오답을 복원하는 개인 기록 도구다. 문제 원문 전체보다 정답을 가르는 조건을 자기 말로 요약하세요.

관련 개념

오류 유형에 맞는 상세 설명 찾기

  • 전제 · 문제 유형과 분석 모형 — 목표변수와 필요한 출력부터 잘못 분류했는지 확인한다.
  • 적용 · 분할 단위와 데이터 누수 — 예측 시점과 학습·평가의 경계를 빠뜨렸는지 확인한다.
  • 전제 · 가설검정의 조건과 해석 — 가정·유의수준·p값의 역할을 서로 바꾸지 않았는지 확인한다.
  • 비교 · 분류지표의 기준집단 — 정밀도·재현율·특이도의 분모를 구분한다.
  • 평가 · 검증과 최종 시험의 역할 — 모형 선택과 최종 성능 확인에 같은 자료를 쓰지 않았는지 확인한다.
