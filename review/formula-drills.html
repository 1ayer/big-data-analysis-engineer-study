시험장 풀이 순서

분모와 기준집단을 먼저 확인하세요

  1. 대상주어진 값이 TP·FP인지, 평균·표준편차인지 표시하세요.
  2. 기준집단“예측 양성 중”, “실제 양성 중”처럼 분모의 대상을 말로 쓰세요.
  3. 단위비율·확률·원래 목표 단위 중 결과가 무엇으로 나와야 하는지 정하세요.
  4. 검산먼저 약분한 뒤 값의 범위와 단위가 정의에 맞는지 확인하세요.

계산기는 사용할 수 없다

DATAQ 수험자 유의사항은 계산기 사용을 금지한다. 복잡한 소수 계산보다 기준집단을 식으로 옮기고 약분한 뒤 크기를 비교하는 순서를 익혀 두세요.

자체 제작 손계산 문제

분모와 단위를 적고 15문제를 푸세요

공식 출제범위를 바탕으로 만든 연습문제이며 실제 기출문제가 아니다. 답을 고른 뒤 해설의 한 줄 계산과 자신의 기준집단을 대조하세요.

  1. 평균 70, 표준편차 5인 점수에서 80의 z 점수는?

    1. 1
    2. 2
    3. 5
    4. 10
    정답과 선택지 해설

    B. (80−70)/5=10/5=2다. 평균보다 표준편차 두 배만큼 높다.

  2. 최솟값 20, 최댓값 60일 때 40의 최소-최대 변환값은?

    1. 0.25
    2. 0.5
    3. 0.67
    4. 2
    정답과 선택지 해설

    B. (40−20)/(60−20)=20/40=0.5다.

  3. Q1=12, Q3=20일 때 1.5IQR 규칙의 아래·위 경계는?

    1. 0과 32
    2. 4와 28
    3. 8과 24
    4. 12와 20
    정답과 선택지 해설

    A. IQR=8, 1.5IQR=12이므로 12−12=0, 20+12=32다.

  4. A가 40건이고 A와 B가 함께인 경우가 30건이다. P(B|A)는?

    1. 0.3
    2. 0.4
    3. 0.75
    4. 1.33
    정답과 선택지 해설

    C. P(A∩B)/P(A)=30/40=3/4=0.75다.

  5. 성공확률 1/2인 독립 시행을 3번 했을 때 정확히 2번 성공할 확률은?

    1. 1/8
    2. 1/4
    3. 3/8
    4. 1/2
    정답과 선택지 해설

    C. C(3,2)(1/2)²(1/2)=3/8이다.

  6. 표준편차가 같을 때 표본 수를 100에서 400으로 늘리면 평균의 표준오차는?

    1. 4배
    2. 2배
    3. 그대로
    4. 절반
    정답과 선택지 해설

    D. SE=s/√n이므로 n이 네 배면 분모가 두 배, SE는 절반이다.

  7. 95% 신뢰구간의 올바른 해석은?

    1. 계산된 한 구간에 모수가 있을 확률이 언제나 95%다.
    2. 같은 절차를 반복하면 약 95%의 구간이 참 모수를 포함한다.
    3. 표본의 95%가 구간 안에 있다.
    4. 귀무가설이 참일 확률이 95%다.
    정답과 선택지 해설

    B. 고정된 모수에 대한 구간 구성 절차의 장기적 포함률이다. A·D는 빈도주의 해석과 다르다.

  8. TP=30, FP=10일 때 정밀도는?

    1. 0.5
    2. 0.6
    3. 0.75
    4. 0.9
    정답과 선택지 해설

    C. 양성 예측 40건 중 실제 양성 30건이므로 30/40=0.75다.

  9. TP=30, FN=20일 때 재현율은?

    1. 0.4
    2. 0.6
    3. 0.75
    4. 1.5
    정답과 선택지 해설

    B. 실제 양성 50건 중 30건을 찾았으므로 30/50=0.6이다.

  10. 정밀도 0.75, 재현율 0.6일 때 F1은 약 얼마인가?

    1. 0.45
    2. 0.60
    3. 0.67
    4. 0.75
    정답과 선택지 해설

    C. 2×0.75×0.6/(0.75+0.6)=0.9/1.35=2/3≈0.67이다.

  11. TN=80, FP=20일 때 특이도와 거짓 양성률(FPR)은?

    1. 0.8과 0.2
    2. 0.2와 0.8
    3. 0.8과 0.8
    4. 1과 0
    정답과 선택지 해설

    A. 특이도=80/100=0.8, FPR=1−특이도=0.2다.

  12. 오차가 2, −2, 4, −4일 때 MAE와 RMSE의 관계로 옳은 것은?

    1. MAE=3이고 RMSE=√10으로 RMSE가 더 크다.
    2. MAE=0이고 RMSE=0이다.
    3. MAE=√10이고 RMSE=3이다.
    4. 둘 다 12다.
    정답과 선택지 해설

    A. MAE=(2+2+4+4)/4=3, RMSE=√((4+4+16+16)/4)=√10≈3.16이다.

  13. 100건 중 A 40건, B 50건, 동시 30건일 때 A→B의 향상도는?

    1. 0.6
    2. 0.75
    3. 1
    4. 1.5
    정답과 선택지 해설

    D. 신뢰도 30/40=0.75를 B의 기준확률 0.5로 나누면 1.5다.

  14. 한 노드의 클래스 비율이 3/4와 1/4일 때 지니 불순도는?

    1. 0.25
    2. 0.375
    3. 0.5
    4. 0.625
    정답과 선택지 해설

    B. 1−(3/4)²−(1/4)²=1−9/16−1/16=6/16=0.375다.

  15. 한 점의 군집 내 평균거리 a=2, 가장 가까운 다른 군집 평균거리 b=6일 때 실루엣은?

    1. −2/3
    2. 1/3
    3. 2/3
    4. 3
    정답과 선택지 해설

    C. (6−2)/max(2,6)=4/6=2/3이다. 1에 가까울수록 해당 점이 자기 군집에 더 잘 모였다고 본다.

오답마다 어떤 값을 분모로 두었는지, 결과가 어떤 단위여야 했는지 적어 보세요. 계산 실수라면 약분과 범위 검산 중 빠진 단계를 표시하세요.

관련 개념

공식의 정의와 적용 범위 확인하기

  • 적용 · 표준화와 최소-최대 변환 — 중심·척도와 변환값 범위를 구분한다.
  • 전제 · 조건부확률과 확률분포 — 조건 사건이 분모가 되는 이유를 확인한다.
  • 적용 · 표준오차와 신뢰구간 — 표본 수와 추정량의 흔들림을 연결한다.
  • 비교 · 정밀도·재현율·특이도 — 예측 집단과 실제 집단의 분모를 가른다.
  • 평가 · 회귀와 군집 지표 — MAE·RMSE의 단위와 실루엣의 범위를 확인한다.
  • 비교 · 지지도·신뢰도·향상도 — 전체 거래, 선행항, 기준확률을 각각 분모로 구분한다.
