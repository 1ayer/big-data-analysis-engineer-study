1과목 · 빅데이터 분석기획

목적 → 근거 → 흐름 → 책임

빅데이터와 가치

  • 빅데이터의 판단 기준은 절대 용량이 아니라 규모·다양성·속도·변동성 등의 특성 때문에 확장 가능한 아키텍처가 필요한가이다.
  • 3V와 추가 V: 3V는 Volume·Variety·Velocity다. Veracity·Value·Variability 등 추가 V는 문헌별로 다르므로 뜻을 판별한다.
  • 정형·반정형·비정형: 정형은 고정 스키마, 반정형은 키·태그 등 자체 구조, 비정형은 내용에서 별도 특징 추출이 필요하다.
  • 데이터·정보·지식·지혜(DIKW): Data → Information → Knowledge → Wisdom. 맥락·패턴 이해·판단이 추가된다.
  • 기술·진단·예측·처방 분석은 “무슨 일 → 왜 → 앞으로 → 무엇을 할지”에 답한다.
  • AI·머신러닝·딥러닝의 관계: AI ⊃ 머신러닝 ⊃ 딥러닝. 빅데이터 플랫폼은 AI 학습에 쓰일 수 있지만 같은 개념은 아니다.
  • 분석조직 형태: 집중형은 전문성·표준화, 분산형은 현업 실행, 연합형은 둘의 결합에 무게를 둔다.
  • 데이터 산업 가치사슬: 생성·수집 → 유통·중개 → 구축·가공 → 분석·서비스에서 어떤 가치를 더하는지 본다.
  • 플랫폼 구성요소: HDFS는 분산 저장, YARN은 자원 관리, MapReduce·Spark는 분산 처리, Hive는 질의, Kafka는 이벤트 전달에 초점을 둔다.
  • 빅데이터의 위험: 데이터가 많아도 대표성·정확성·공정성은 자동 보장되지 않는다.

분석기획

  • 분석 문제 정의: 업무 목표·의사결정 → 분석 단위·목표변수·기준시점·관측창·예측창 → 수용 지표·비용·제약 순으로 구체화한다.
  • 하향식과 상향식 발굴: 하향식은 전략·업무 문제, 상향식은 데이터·패턴에서 출발하며 실제 과제는 둘을 반복한다.
  • 산업 간 데이터 마이닝 표준 프로세스(CRISP-DM): 업무 이해 → 데이터 이해 → 준비 → 모델링 → 평가 → 배포. 순서는 엄격하지 않다.
  • 데이터베이스 지식발견(KDD): 선택 → 전처리 → 변환 → 데이터마이닝 → 해석·평가. 데이터마이닝은 전체 과정의 한 단계다.
  • 과제 우선순위는 가치·데이터 준비도·기술·조직 실행성·위험을 함께 본다.
  • 프로젝트 계획은 한 과제, 마스터 플랜은 포트폴리오와 공통 기반의 중장기 로드맵이다.

수집·저장·법제

  • 배치와 스트림: 배치는 모은 뒤 주기 처리, 스트림은 연속 이벤트 처리다. 스트림은 지연·순서·중복·멱등성을 설계한다.
  • robots.txt의 범위: 크롤러 접근 규칙이지 저작권·계약·개인정보상 이용 권한이 아니다.
  • 데이터 품질: 정확성·완전성·유효성·일관성·적시성·유일성. 체크섬은 의미적 정확성이 아니라 바이트 무결성을 본다.
  • 가명정보와 처리 근거: 가명정보도 개인정보다. 동의는 수집·이용의 여러 법적 근거 중 하나다.
  • 익명처리의 판단: 이름 삭제·마스킹만으로 익명정보가 되지는 않는다. 외부 결합 가능성과 남은 식별 위험을 다시 본다.
  • 가명정보 특례: 통계작성·과학적 연구·공익적 기록보존 등에는 법이 정한 조건 아래 특례가 있다.
  • 추출·변환·적재(ETL)와 추출·적재·변환(ELT): 변환이 적재 전인지 후인지 구분한다.
  • 하둡 분산 파일 시스템(HDFS)과 MapReduce: NameNode는 메타데이터, DataNode는 블록을 맡는다. 처리 흐름은 Map → Shuffle·Sort → Reduce다.

2과목 · 빅데이터 탐색

자료형 → 분포 → 추론

전처리와 탐색

  • 결측 원인과 대체 영향: 완전 무작위(MCAR)·무작위(MAR)·비무작위 결측(MNAR) 가능성을 검토한다.
  • 사분위 범위(IQR) 이상값 경계: Q1 − 1.5×IQR, Q3 + 1.5×IQR. 이상값은 오류가 아니라 희귀한 참값일 수도 있다.
  • 표준화와 최소-최대 정규화: z=(x−평균)/표준편차, 정규화=(x−최솟값)/(최댓값−최솟값).
  • 파생변수의 기준시점: 날짜·비율·집계에는 예측 기준시점 이전 정보만 쓴다. 비율은 분모 0과 단위를 확인한다.
  • 측정척도와 가능한 연산: 명목·순서·등간·비율 척도에 가능한 연산이 다르다. 섭씨 20도는 10도의 두 배라는 의미가 없다.
  • 중심과 산포: 평균은 이상값에 민감하고 중앙값은 강건하다. 분산·표준편차·IQR은 산포를 본다.
  • 왜도와 첨도: 왜도는 비대칭, 첨도는 꼬리와 극단값 경향을 설명한다. 상관은 인과가 아니다.
  • 확장 탐색적 데이터 분석(EDA): 시공간은 분모·투영·인접 의존성, 다변량은 스케일·쌍별 관계, 비정형은 내용·메타데이터와 누수를 먼저 본다.

확률과 추론

  • 조건부확률과 독립: P(A|B)=P(A∩B)/P(B). 독립이면 P(A∩B)=P(A)P(B).
  • 기대값과 분산: 기대값은 확률가중 평균, 분산은 평균에서 제곱거리의 기대값이다.
  • 이항분포와 포아송분포: 이항분포는 고정 시행 수·독립·두 결과·일정 성공확률, 포아송분포는 구간 내 사건 수를 다룬다.
  • 모수·통계량·표준오차: 표본통계량은 표본에서 계산하고 모수는 모집단 특성이다. 표준오차는 통계량의 표본추출 변동이다.
  • 95% 신뢰구간은 같은 절차를 반복할 때 약 95%의 구간이 참 모수를 포함한다는 장기적 성질이다.
  • p값의 해석: 귀무가설 아래 관측값 이상 극단적인 자료가 나올 확률이지 귀무가설이 참일 확률이 아니다.
  • 제1·2종 오류와 검정력: 제1종 오류는 참인 H0 기각(α), 제2종 오류는 거짓 H0를 기각하지 못함(β), 검정력=1−β다.

3과목 · 빅데이터 모델링

목표변수 → 경계 가정 → 검증

설계와 지도학습

  • 목표변수와 학습 유형: 연속 목표는 회귀, 범주 목표는 분류, 정답 없이 구조를 찾으면 군집·차원축소 등 비지도학습이다.
  • 학습·검증·시험의 역할은 다르다. 전처리·특징선택도 학습 자료에서 적합해 누수를 막는다.
  • 시계열 분할은 미래가 과거 학습에 섞이지 않도록 시간 순서를 보존한다.
  • 선형회귀와 로지스틱 회귀: 선형회귀는 E(Y|X)의 선형 구조를, 로지스틱 회귀는 로그오즈의 선형 구조를 가정한다.
  • 로지스틱 회귀계수: exp(β)는 다른 변수가 같을 때 X 1 증가에 따른 오즈비다. 확률이 β만큼 증가한다는 뜻이 아니다.
  • Ridge와 Lasso: Ridge(L2)는 제곱계수 벌점으로 축소하고 Lasso(L1)는 절댓값 벌점으로 일부 계수를 0으로 만들 수 있다.
  • 의사결정나무는 불순도 감소로 분할하고, 서포트 벡터 머신(SVM)은 마진을 최대화하며, 인공신경망은 층·활성화와 역전파로 비선형 관계를 학습한다.

비지도·고급기법

  • 연관규칙 지표: 지지도 P(A∩B), 신뢰도 P(B|A), 향상도 P(B|A)/P(B). 향상도 1은 독립 수준이다.
  • k-평균(k-means)은 군집 내 제곱거리를 최소화하고 k를 미리 정하며 이상값·척도·초기값에 민감하다.
  • 계층 군집은 덴드로그램을 만들며 연결법에 따라 결과가 달라진다.
  • 밀도기반 공간 군집(DBSCAN)은 임의 모양 군집과 잡음을 찾지만 밀도 차이가 크면 어렵다.
  • 주성분분석(PCA)은 분산이 큰 직교 방향으로 선형 투영한다. 지도 레이블을 쓰지 않으므로 예측에 최적인 축을 보장하지 않는다.
  • 다변량 기법: PCA는 분산 축, 요인분석은 잠재요인, LDA는 레이블을 이용한 판별 축, MANOVA는 여러 결과변수의 평균벡터 차이를 본다.
  • 딥러닝 구조: CNN은 국소 패턴, RNN·LSTM은 순서 의존성, 어텐션은 입력 요소 사이의 중요한 관계에 가중치를 둔다.
  • 배깅과 부스팅: 배깅은 병렬 학습 결과를 평균·투표해 분산을 낮추고, 부스팅은 앞선 오류를 순차 보완한다.
  • 시계열 정상성은 평균·분산·자기공분산 구조가 시간에 따라 안정적인 성질을 뜻한다.

4과목 · 빅데이터 결과해석

지표 → 오류비용 → 행동 → 감시

평가와 개선

  • 혼동행렬 지표: 정확도=(TP+TN)/전체, 정밀도=TP/(TP+FP), 재현율=TP/(TP+FN), 특이도=TN/(TN+FP).
  • F1과 클래스 불균형: F1은 정밀도와 재현율의 조화평균이다. 클래스 불균형에서는 정확도 하나로 판단하지 않는다.
  • 수신자 조작 특성-곡선하면적(ROC-AUC)과 정밀도-재현율(PR) 곡선: 하나는 순위 분리 능력, 다른 하나는 희귀 양성의 예측 품질을 본다.
  • 회귀 지표: 평균절대오차(MAE)는 절대오차 평균, 평균제곱오차(MSE)·평균제곱근오차(RMSE)는 큰 오차를 더 강하게 벌한다.
  • 교차검증과 최종 시험: 교차검증은 일반화 성능 추정·모형 선택에 쓰고 최종 시험 자료는 마지막에 한 번 사용한다.
  • 과소적합과 과대적합: 학습·검증 모두 낮은 성능은 과소적합, 학습만 높고 검증이 낮으면 과적합 가능성이 크다.
  • 분류 임계값은 오류 비용과 처리 용량에 맞춘다. 모형 재학습 없이도 혼동행렬이 바뀐다.
  • 추론과 예측 평가: 계수 p값은 효과 크기나 귀무가설이 참일 확률이 아니다. 적합도와 독립 자료 예측성능도 구분한다.
  • 스태킹 누수 방지: 메타모형은 각 행을 보지 않은 기본모형의 out-of-fold 예측으로 학습한다.

해석·활용·모니터링

  • 전역 해석과 지역 해석: 전역 해석은 전체 행동, 지역 해석은 한 예측의 근거를 설명한다.
  • 순열 중요도는 한 변수를 섞을 때 평가 점수가 얼마나 떨어지는지 본다. 상관 변수는 서로 대체할 수 있다.
  • 부분의존그림(PDP)과 개별조건부기대(ICE): PDP는 개별 예측 반응을 평균내고 ICE는 사례별 반응선을 보인다.
  • 연관과 인과의 경계: 변수 중요도·계수는 모형이 이용한 연관이지 자동 인과증거가 아니다.
  • 데이터·개념 드리프트: 데이터 드리프트는 P(X), 개념 드리프트는 P(Y|X)의 변화다.
  • 운영 모니터링은 입력·파이프라인·예측·성과·집단별 성능과 핵심성과지표(KPI)를 함께 본다.
  • 모형 전개·활용 시나리오는 대상·입력 시점·임계값·행동·예외처리·롤백을 업무 흐름으로 정하고, 리모델링은 변화 원인을 확인한 뒤 문제·데이터·모형·정책을 함께 재검토한다.
  • 업무 활용 가치: 오프라인 점수보다 기준선 대비 순편익, 적용률, 사용자 행동과 안전 제약이 최종 가치를 결정한다.
  • 시각화와 인포그래픽: 비교·관계·공간 시각화는 질문이 다르다. 출처·기간·단위·분모·한계를 남긴다.
